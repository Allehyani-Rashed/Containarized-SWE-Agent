# Refactor Plan – ui-ux-improvements vs main

## Context
- `app/app/main.py` now spans ~1,240 lines (helpers + endpoints roughly lines 90–1,214) combining router wiring, credential + concurrency helpers, and every projects/tasks/integrations route inside one file. Only the embedded `integrations_router` is isolated, so the modular router pattern from `origin/main` is effectively gone.
- `app/app/worker.py` has grown past 1,400 lines with `TaskQueueManager` handling queue orchestration, concurrency limits, credential broadcasts, proxy allowlist refreshes, log snapshots, and Codex invocation details in one class.
- `app/app/codex_runner.py` (~600 lines) mixes Docker Compose bootstrapping, Tinyproxy environment shaping, shim vs. real Codex execution, result parsing, abort handling, and log capture without clear seams for testing.
- `app/app/project_cache.py` is now ~1,300 lines covering metadata IO, locking (including the new breakout sentinel protections), git orchestration, metrics, and CLI logging; `scripts/project_cache.py` still reconstructs cache identifiers and logging callbacks manually.
- `app/app/metrics.py` continues to touch Prometheus internals via `REGISTRY._names_to_collectors`, which is brittle and now feeds both the worker and Codex runner metrics.
- `ui/src/pages/TaskListPage.tsx` has ballooned to ~1,500 lines as it owns filters, polling, credential banners, log streaming, archive snapshots, and mutation modals in a single component.
- `ui/src/App.css` remains a global catch-all despite the newer component-scoped styles, risking regressions as the navigation/setting pages evolve.
- `ui/src/pages/ProjectsPageOld.tsx.bak` keeps an obsolete backup component checked in.
- `ui/src/hooks/useProjectsData.tsx` still blanket-disables `@typescript-eslint/no-unused-vars` / `no-unused-vars`, hiding real lint issues as the projects dashboard grows.

## Phase 2 – Isolate worker scheduling, runtime state, and metrics

- [x] Split queue orchestration into a dedicated scheduler component (e.g., `WorkerScheduler`) while trimming `TaskRuntimeState` to focused bookkeeping APIs for logs, credential snapshots, and abort signals. *(New `app/app/worker_scheduler.py` owns queueing; `TaskRuntimeState` now only tracks logs/credentials/abort markers.)*
